# AutoDeploy

## Запуск
Для работы необходимы:  
- Python 3  
- Библиотека `psycopg2`  
- Доступ к базе данных  

Создание папки для проекта:  

```bash
mkdir -p "$HOME/AutoProject"
```
Клонирование репозитория:
```bash
git clone https://github.com/Stikman71/AutoDeploy "$HOME/AutoProject"
```
Измените подключение к базе данных в файле:
```
$HOME/AutoProject/conf.ini
```

Запуск скрипта настройки cron
```bash
bash $HOME/AutoProject/setup.sh
```

## sql
Таблица создается динамический
db_init.py -> create_tables()

## Описание
* **db_init.py** - иницилизация бд для дальнейшей работы
* **db_schema.json** - хранися схема бд

* **generator.py** - генератор для тестовых данных
* **load_data_db.py** - загрузка тестовых данных в бд

* **conf.ini** - конфигурация - указать данные для подключения к бд, дирикторию для сохранения файлов из generator
- setup.sh — устанавливает автоматический запуск скрипта через `cron`.  
  При первом запуске происходит:  
  - первичная инициализация базы данных,  
  - генерация тестовых данных,  
  - запись данных в базу.  

- daily_run.sh — скрипт запуска, который выполняется в зависимости от текущего дня недели
